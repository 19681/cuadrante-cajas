# 🗂️ Cuadrante de Cajas - Family Cash

Aplicación web intuitiva y automatizada para la gestión de turnos, horarios y cuadrantes del personal de cajas en Family Cash. Diseñada para agilizar el control semanal, la acumulación mensual de horas y la comunicación fluida del equipo.

## ✨ Características Principales

* **Selector de Historial de Semanas:** Permite navegar entre semanas anteriores para consultar o reutilizar cuadrantes pasados.
* **Auto-Clonado y Limpieza:** Opción para clonar la semana anterior de forma automática o restablecer los turnos a "LIBRE" con un solo clic.
* **Gestión Visual de Empleados:** Añade, edita o da de baja a trabajadores de la plantilla de manera dinámica.
* **Cálculo de Acumulado Mensual:** Resumen general e instantáneo de las horas trabajadas por todo el personal durante el mes.
* **Exportación y Comunicación:**
  * 📥 **Exportar a CSV:** Descarga los datos listos para hoja de cálculo.
  * 🖨️ **Diseño de Impresión:** Vista limpia optimizada para papel sin elementos molestos.
  * 📱 **Generador de WhatsApp:** Crea mensajes formateados listos para enviar por WhatsApp al personal.

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Diseño moderno y adaptable)
* **JavaScript (Vanilla ES6)** (Lógica de turnos, almacenamiento local y automatizaciones)
* **LocalStorage** (Persistencia de datos segura directamente en el navegador del usuario)
